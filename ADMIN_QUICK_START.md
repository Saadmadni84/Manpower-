# 🚀 Admin System Quick Start Guide

## Step 1: Start the Application

```bash
cd /Users/saadmadni/Downloads/Python/company
npm start
```

OR use the full-stack start script:

```bash
./scripts/start-fullstack.sh
```

## Step 2: Access Admin Panel

1. **Open your browser** to: `http://localhost:3000`

2. **Click the "Admin" button** in the header navigation (right side)

3. You'll be redirected to the **Admin Login Page**

## Step 3: Login

**Enter the credentials:**
- **Email:** `admin@company.com`
- **Password:** `Admin@123`

Click **"Sign In"**

## Step 4: Explore the Admin Panel

After login, you'll see the **Dashboard** with:
- Company statistics
- Recent activities
- Quick action buttons

### Navigate using the sidebar:

1. **Dashboard** - Overview and stats
2. **Website Content** - Edit About Us, Vision, Mission
3. **Services** - Manage services (Add/Edit/Delete)
4. **Clients** - Manage client portfolio
5. **Contracts** - View and manage contracts
6. **Careers & Jobs** - Manage job postings and view applications
7. **Gallery** - Upload and manage images
8. **Contact Enquiries** - View customer messages

## 🎯 Common Tasks

### Add a New Service:
1. Go to **Services** from sidebar
2. Click **"Add New Service"** button
3. Fill in service details
4. Click **"Add Service"**

### View Job Applications:
1. Go to **Careers & Jobs** from sidebar
2. Click **"Applications"** tab
3. Click **"Download CV"** to download applicant resumes

### Edit Company Information:
1. Go to **Website Content** from sidebar
2. Click **"Edit"** on any section
3. Update the content
4. Click **"Save"**

### View Contact Enquiries:
1. Go to **Contact Enquiries** from sidebar
2. View all customer messages
3. Click eye icon to view details

## 🔐 Security Features

- ✅ Account locks after 5 failed login attempts
- ✅ Password must be strong
- ✅ Session timeout after inactivity
- ✅ Remember me functionality
- ✅ Protected routes (must be logged in)

## 🚪 Logout

Click your **avatar** in the top-right corner → Click **"Logout"**

## 📱 Access from Main Website

The Admin button is always visible in the main website header. Click it anytime to access the admin panel.
